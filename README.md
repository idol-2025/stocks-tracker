# Engineering Common Materials - Inventory Management System

A clean and responsive inventory dashboard built using HTML and CSS.

## Features
- Search materials by name, item number, or specification
- See in-stock, out-stock, and remaining counts
- Basic action icons (reorder, edit, delete)
- Clean, modern UI

## Usage
Open `index.html` in a browser.

- Connect to a backend or local storage
